# 📊 Dashboard de Análise de Vendas de Vestuário

> **⚠️ Nota de Esclarecimento:** Este é um projeto acadêmico/prático. Todos os dados, marcas e valores apresentados neste dashboard são estritamente **fictícios** e foram criados exclusivamente para fins de estudo e demonstração de habilidades em análise de dados.

## 📝 Sobre o Projeto
Este projeto consiste em um dashboard interativo desenvolvido no **Power BI** para analisar o desempenho de vendas, comparando custos, receitas e volumes por categoria de produtos e marcas. 

O objetivo principal desta atividade é demonstrar a capacidade de transformar dados brutos em insights visuais claros e de fácil interpretação para a tomada de decisão.

## 🎯 Principais Análises e Indicadores
* **Desempenho por Categoria:** Análise do Valor Total gerado por diferentes tipos de produtos (Camisas, Sandálias, Bonés, Sapatos, Casacos, etc.).
* **Análise de Margem por Marca:** Comparativo direto entre a **Soma de Custo de Compra** e a **Soma de Valor de Venda** segmentado por marcas (Hering, Reserva e Osklen), permitindo visualizar a margem de lucro de cada uma.
* **Identificação de Top Sellers:** Visualização rápida dos itens com maior volume financeiro transacionado.

## 🛠️ Ferramentas Utilizadas
* **Power BI:** Importação de dados, modelagem, criação de medidas (DAX) e construção das visualizações.

## 🚀 Como visualizar o projeto
1. Clone este repositório: `git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git`
2. Certifique-se de ter o [Power BI Desktop](https://powerbi.microsoft.com/desktop/) instalado na sua máquina.
3. Abra o arquivo `produtos.pbix` para interagir com o dashboard e visualizar a modelagem dos dados.
